# Brand asset attribution

These local assets are used in this frontend prototype without changing the logos themselves. Display sizing uses `object-fit: contain`; the favicon is a square crop of the NPL emblem for legibility at small sizes. The NPL/CAN lockup places the original marks side-by-side and labels CAN as the governing association; it does not claim ownership, endorsement, or a joint commercial brand.
